## Large files are not in git
To keep the repository small the raw evidence is NOT committed: videos (`videos/*.mp4`), point clouds (`point_clouds/*.ply`), scans and frames (`*.npz`, `*.npy`), and run archives (`*.zip`). They exist on the lab PC under `Media/Grasp/<run>/` (`videos/`, `point_clouds/`, `scan/`, `plan/`). Everything else of every run is committed: README, failure analysis, config, metrics, trajectory CSV, logs, plots and screenshots. The run READMEs still name the missing files; regenerate the derived ones with `python3 Code/Grasp/ros2_iface/export_evidence.py <run dir>` where the scan is available, or move the large files to Git LFS if they should be versioned.

## Names in the older run documents (renamed on 2026-11-07, after those runs)
The pipeline was renamed from "green" to colour-marker names because the marker colour is a setting (`color_marker.h / s_min / v_min`), not a rule. The run documents above keep the names of the time. Mapping: runner `run_green_pipeline.py` -> `run_pipeline.py`; services `green` -> `color_target`, `green_grasp` -> `sticker_grasp`; config block `green` -> `color_marker` (`green_eps_m` / `green_min_pts` -> `marker_eps_m` / `marker_min_pts`); modules `housing_grasp/green.py` / `green_report.py` -> `color_marker.py` / `color_marker_report.py`; functions `green_mask / green_points / green_frame` -> `marker_mask / marker_points / marker_frame`; topic `/grasp/green_cloud` -> `/grasp/marker_cloud`; saved files `green_cloud.npy`, `green_close_points.npy`, `green_analysis.json` -> `marker_cloud.npy`, `marker_close_points.npy`, `color_analysis.json`. `export_evidence.py` still reads the old file names. Run folder names are unchanged.
